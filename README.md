# 百度贴吧页面原型 - 功能拆分版

本项目基于原始的`贴吧页面原型.html`文件,将各个功能模块拆分为独立的单页面,并保持统一的设计风格。

## 📁 项目结构

```
实例1/
├── common.css              # 公共样式文件(✅ 已完成)
├── index.html             # 首页(✅ 已完成)
├── tieba-list.html        # 贴吧列表页(✅ 已完成)
├── tieba-detail.html      # 贴吧详情页(✅ 已完成)
├── post-detail.html       # 帖子详情页(✅ 已完成)
├── create-post.html       # 发帖页面(✅ 已完成)
├── user-profile.html      # 用户中心页面(✅ 已完成)
└── README.md             # 项目说明文件
```

## ✅ 已完成页面

### 1. common.css - 公共样式文件
包含所有页面共用的样式:
- 基础样式重置和响应式设置
- CSS变量定义(颜色、间距、圆角等)
- 导航栏样式
- 按钮样式(primary、secondary、success等)
- 表单样式(input、select、textarea)
- 页脚样式
- 卡片样式
- 标签样式
- 工具类(间距、文本对齐等)

### 2. index.html - 首页
功能模块:
- **导航栏**: 包含logo、菜单链接、登录注册按钮
- **英雄区**: 欢迎标题、描述文字、搜索框
- **轮播图**: 4张精选推荐图片,支持自动播放和手动切换
- **热门贴吧**: 6个热门贴吧卡片,网格布局
- **热门帖子**: 3个热门帖子列表
- **页脚**: 4栏信息链接

### 3. tieba-list.html - 贴吧列表页
功能模块:
- **搜索过滤栏**: 搜索框、分类选择器、排序选择器
- **贴吧网格**: 8个贴吧卡片,包含:
  - 贴吧头像
  - 贴吧名称和描述
  - 成员数和帖子数统计
  - 关注按钮
- **分页组件**: 页码导航

## 🎨 设计特点

### 统一的视觉风格
- **色彩系统**: 使用CSS变量定义主题色
  - 主色: #007AFF (蓝色)
  - 辅助色: #5856D6 (紫色)
  - 成功色: #34C759 (绿色)
  - 警告色: #FF9500 (橙色)
  - 错误色: #FF3B30 (红色)

- **圆角设计**:
  - 小圆角: 8px (按钮、输入框)
  - 中圆角: 12px (卡片)
  - 大圆角: 16px (大型容器)

- **阴影层次**:
  - 轻阴影: 用于卡片默认状态
  - 中阴影: 用于悬停效果
  - 重阴影: 用于强调元素

### 响应式设计
- **桌面端** (>768px): 多列网格布局,完整导航
- **平板端** (768px): 自适应列数,折叠导航
- **移动端** (<480px): 单列布局,汉堡菜单

### 交互效果
- **悬停效果**: 卡片上浮、颜色变化、阴影增强
- **过渡动画**: 所有交互使用平滑过渡
- **轮播自动播放**: 5秒自动切换

### 4. tieba-detail.html - 贴吧详情页(已完成)
功能模块:
- **贴吧头部**: 包含头像、名称、描述、统计数据(成员、帖子、今日发帖)
- **操作栏**: 发帖按钮、关注按钮、搜索框
- **筛选标签**: 全部、精华、热门、最新
- **帖子表格**: 标题、作者、回复/浏览数、最后回复时间
- **标签系统**: 精华、攻略、讨论、求助等多种标签
- **分页导航**: 页码切换功能

### 5. post-detail.html - 帖子详情页(已完成)
功能模块:
- **帖子内容**: 完整标题、正文、图片展示
- **作者信息**: 头像、名称、等级、统计数据
- **互动按钮**: 点赞、评论、分享、收藏(带计数)

### 6. create-post.html - 发帖页面(已完成)
功能模块:
- **表单字段**: 标题、选择贴吧、内容编辑
- **富文本编辑器**: 包含粗体、斜体、下划线、列表、对齐等功能

- **标签选择**: 精华、攻略、讨论、求助、分享、评测

## 🚀 使用方法

1. 直接在浏览器中打开任意HTML文件即可查看
2. 所有页面通过导航栏互相链接
3. 确保所有文件在同一目录下,以保证样式正确加载

## 📝 技术特点

- **纯HTML/CSS/JS**: 无需任何构建工具或框架
- **语义化HTML**: 使用语义化标签提高可访问性
- **CSS变量**: 便于主题定制和维护
- **Flexbox + Grid**: 现代布局技术
- **移动优先**: 响应式设计适配各种设备
